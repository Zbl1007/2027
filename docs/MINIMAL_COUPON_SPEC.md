# 3D-ICE—COMSOL 最小一致算例

日期：2026-10-16。用户已授权开始实施；热后端指定为 Zbl1007/3d-ice，COMSOL 在用户另一台电脑上运行。

## 目标与证据边界

交付可重复生成、运行和比较的小算例及外部 COMSOL 任务包。首先验证单位、热源、坐标、边界和温度输出；随后验证异质材料。每次计算保存输入 hash、后端版本、原始日志和输出。只有收到真实 COMSOL 结果并检查后，才能声明交叉验证完成。

所有本轮小模型标为 `synthetic_fixture`。从官方样例或文献引用材料数值，用显式的测试几何和载荷隔离接口问题。这些不是 TAP 产品参数，不自动关闭研究案例缺口，不写入其 `selected_value`。未知应力仍为 null。

## 验证顺序

1. H0：均匀硅长方体，体积均匀发热，顶面对流，其余面绝热。比较 3D-ICE 的单元中心温度与一维解析解；检查三个 z 分辨率。COMSOL 用相同连续体问题及固定采样点作独立参考。
2. H1：显式、互不重叠的铜核—SiO2 衬层—硅区域。首个接口验证采用矩形截面，保证两后端几何完全相同；它不等同于圆柱 TSV，不用于实际孔附近应力结论。检查材料、功率、体积和移动后模型输入传播。圆柱 TSV 的离散几何误差作为后续单独验证。
3. M0：COMSOL 单材料自由热膨胀、轴向约束杆。解析结果只用于验证真实求解输出，绝不填作机械求解结果。
4. M1：用户完成 H1 热验证后，在 COMSOL 对相同铜/衬层/硅实体做小变形线弹性分析，先统一温升，再使用温度场。保持真实求解状态和覆盖范围；尖角峰值不作为可靠性结论。

## 最小实现

- `cases/minimal_coupons/` 保存 SI 主数据、来源和验收标准。
- `scripts/` 提供依赖锁定/构建、任务包生成、3D-ICE 运行、外部结果校验入口；不实现新的离散热或机械求解器。
- `external/3d-ice/` 为可运行的锁定源码 checkout，忽略于 Git；不可执行 `references/` 中的历史脚本。
- `verification/` 保存当前验证证据；可携带 COMSOL 包保存在本项目中。
- COMSOL 包提供几何/材料/边界/热源/机械约束、采样坐标、结果格式、真实日志要求和回填命令。无许可证的本机不生成虚假 `.mph`。

## 验收

- 单位转换可逆，区域覆盖无孔洞/重叠，功率合计正确。
- H0 真实 3D-ICE 结果与解析解比较，误差随 z 网格细化下降。
- H1 输出是真实 3D-ICE 解；没有外部参考时只报告已运行，不能标为精度已验证。
- 外部回填拒绝缺行、重复坐标、错误输入 hash、非有限数、未求解/模拟结果和单位不匹配。
- 材料依据与测试定义均可追溯，TAP 研究输入保持未采用状态。
- 执行 `python3 scripts/validate_provenance.py` 及针对新增适配/导入行为的检查。
